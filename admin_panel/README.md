# Lebanon Locals Admin Panel

Professional admin panel for managing the Lebanon Locals platform.

## Quick Start

### Local Development

```bash
# From frontend_bundle directory
php -S 127.0.0.1:8081 -t admin_panel
```

Access at: http://localhost:8081

### Production Access

https://admin.lebanonlocals.com

## Default Admin Login

**Email**: admin@lebanonlocals.com  
**Password**: Set in database
